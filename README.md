# 발로 에임 트레이너

발로란트 **인게임 감도·FOV·이동속도를 그대로 옮긴** 브라우저 3D 에임 트레이너입니다.
훈련 결과를 분석해 **에임 교정 조언**을 해주고, 블라인드 테스트로 **감도를 추천**합니다.

## 가장 쉬운 실행 방법 (설치 없음)

1. [`dist/valo-aim-trainer.html`](dist/valo-aim-trainer.html) 파일을 내려받습니다 (GitHub 파일 화면 오른쪽 위의 다운로드 버튼).
2. 내려받은 파일을 **더블클릭** → 브라우저에서 바로 실행됩니다. (Chrome / Edge 권장)
3. **감도** 탭에서 발로란트 인게임 감도와 마우스 DPI 를 입력하고, **훈련** 탭에서 모드를 고르면 시작.

## Windows 실행파일 (.exe)

`npm run build:win` 으로 `desktop/out/ValoAimTrainer-win-x64.zip` 이 만들어집니다.
압축을 풀고 폴더 안의 `ValoAimTrainer.exe` 를 실행하면 브라우저 없이 전용 창으로 열립니다 (F11 전체화면).
서명되지 않은 프로그램이라 처음 실행 시 Windows 보호 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
실행파일 버전은 프레임 제한과 수직동기화를 꺼서 입력 지연을 줄였습니다.

## 개발자용 실행

코드를 고치면서 실행하려면 Node.js 가 필요합니다. `npm run build` 로 위의 단일 HTML 파일을 다시 만들 수 있습니다.

```bash
npm start          # 또는: node server.js
# → http://localhost:5173 을 Chrome / Edge 로 열기
```

Python 이 있다면 `python -m http.server 5173` 도 됩니다. (ES 모듈이라 `index.html` 을 파일로 직접 열면 동작하지 않습니다.)

## 인게임과 똑같이 맞춘 것

| 항목 | 값 | 위치 |
| --- | --- | --- |
| 감도 | 감도 1.0 에서 1카운트당 **0.07°** (`cm/360 = 914.4 / (0.07 × 감도 × DPI)`) | `js/config.js` |
| FOV | 수평 **103°** 고정 (창 비율에 맞춰 수직 FOV 계산) | `js/game.js` `resize()` |
| 이동 속도 | 칼 6.75 m/s, 라이플·Sheriff 80% (5.4 m/s), Ghost 85%, 걷기 56% | `js/config.js` |
| 정확도 | 최고 속도의 **30% 이하**일 때만 첫 발 정확도 | `js/movement.js` |
| 가감속 | 나·봇 공통. 키 떼면 0.160s 에 완전 정지(약 110ms 에 정확 구간), **카운터 스트레이프 약 55ms**, 0→최고속 0.155s | `js/config.js`, `js/movement.js` |
| 히트박스/데미지 | 머리 = 눈높이, Vandal 헤드 160 / 몸 40 / 다리 34, 150HP | `js/config.js` |
| 마우스 입력 | Pointer Lock **원시 입력**(`unadjustedMovement`) → Windows 감도·가속 무시 | `js/game.js` |

수치는 커뮤니티/위키 기준 값입니다. 패치로 바뀌면 `js/config.js` 만 수정하면 됩니다.
상단 나침반의 각도로 인게임과 같은 거리에 같은 각도가 도는지 확인할 수 있고, 다르면 감도 탭의 **보정 계수**로 맞출 수 있습니다.

## 훈련 모드

- **스트레이프 봇** – 봇이 발로란트 가감속 그대로 ADAD / 카운터 스트레이프로 멈춤. 빗나간 샷이 적 이동 방향의 뒤(뒤처짐)인지 앞(앞서감)인지 분석.
- **코너 피킹 (내가 피킹)** – 벽 뒤에서 D 로 피킹. 적은 5개의 자주 서는 자리 중 하나에서 앵글을 잡고, 나를 본 뒤 설정한 반응 속도가 지나면 쏩니다. 프리에임 오차·이동 중 사격을 측정.
- **앵글 홀드 (적이 피킹)** – 적이 와이드 스윙 / 타이트 피크 / 숄더 피크(미끼 후 피크) / 달려서 가로지르기로 나옵니다. 유형별 승률·반응 속도 표시.
- **플릭** – 머리를 맞혀야 사라지는 타겟. 오버슈팅·언더슈팅·미세 보정 횟수 분석.
- **감도 찾기** – 현재 감도 ×0.8 / 0.9 / 1.0 / 1.1 / 1.25 를 순서를 숨긴 채 테스트 → 점수 곡선(2차 회귀)의 최저점 + 오버/언더슈팅 경향으로 추천 감도 계산.

## 분석 · 조언 항목

- 반응 속도 (적이 보인 순간 → 첫 발, 중앙값)
- 크로스헤어 배치: 적이 처음 보인 순간 머리까지 상하/좌우 각도 오차
- 이동 중 사격 비율 (카운터 스트레이프 여부)
- 플릭 궤적: 오버슈팅 / 언더슈팅 / 미세 보정 횟수
- 트래킹: 빗나간 샷의 뒤처짐 vs 앞서감
- 헤드샷 비율, 연사 비율, 교전 패배율, eDPI 구간
- 감도 탭: eDPI, cm/360, 90° 플릭 거리, 다른 게임(CS2·Apex·OW2) 감도 변환, cm/360 → 감도 계산

기록은 브라우저 `localStorage` 에 최근 100개까지 저장됩니다.

## 구조

```
index.html          UI (메뉴, HUD, 결과)
css/style.css
js/config.js        발로란트 수치 (감도 yaw, FOV, 속도, 히트박스, 무기)
js/sens.js          감도 계산·변환·추천            ← 순수 로직
js/movement.js      가감속·정확도·탄퍼짐            ← 순수 로직
js/bots.js          스트레이프/피킹 봇 AI           ← 순수 로직
js/analysis.js      통계·플릭 궤적 분석·조언 생성    ← 순수 로직
js/game.js          Three.js 렌더링, 입력, 사격, 시야 판정
js/scenarios.js     훈련 모드
js/main.js          UI 연결
test/               node --test 단위 테스트
```

```bash
npm test
```

## 참고

- 브라우저는 Chrome / Edge 권장 (원시 입력 지원). Firefox 는 원시 입력이 없어 Windows 포인터 속도 6/11, "포인터 정확도 향상" 끄기가 필요합니다.
- 반동(화면 튐)은 구현하지 않았고, 연사 시 탄퍼짐 증가로만 표현합니다. 탭/버스트 연습 기준입니다.
- 발로란트/Riot Games 와 무관한 개인 연습용 프로젝트입니다.
